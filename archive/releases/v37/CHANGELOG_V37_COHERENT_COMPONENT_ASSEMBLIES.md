# CHANGELOG V37 — Coherent Residual Component Assemblies

V37 preserves V36's generation order, main routing, 50–60% component service target, and 80–90% local completion of the remaining service budget. It fixes the component-language regression in which residual coverage was increasingly realized by scattered standalone dots/dashes/squares/circles rather than coherent component collections.

## Root cause

- V33 introduced generic gap-sized dot/dash/square/circle mop-up after the normal collection population.
- V35 raised the mop-up allowance from 36 to 260 extra fillers and increased the component residual grid to 56×56.
- V36 inherited that filler generator unchanged. On the reference seed `20260806`, 27 of 47 accepted component groups were generic residual fillers, so the cleanup class numerically dominated the proper collection population despite ample open space.
- The V35/V36 local-clearance adaptation could also scale a medium/large residual motif down toward token size at a locally narrow cell inside an otherwise large connected room.

## V37 correction

- Full prepared collections remain first priority.
- Additional medium/large residual capacity is now supplied by **compound residual assemblies** built from the existing collection grammar.
- Medium/large assemblies contain at least two entity families; large assemblies contain 3–4 families.
- Medium/large assemblies are anchored by structured IC/dense families and retain ordinary/capacitor variation.
- Outer-border probability rises with room scale: approximately 68% small, 82% medium, 92% large for generated residual assemblies.
- Standalone dot/dash/square/circle fillers are restricted to genuinely `micro` connected residual regions and capped at 8 accepted micro fillers per sample.
- Small non-micro rooms may still receive a singleton capacitor; this is treated as a coherent component entity, not generic confetti.
- A compound residual assembly cannot be clearance-shrunk below 72% of its generated instance scale. A narrow candidate cell is skipped instead of crushing the assembly.
- Total residual completion budget is reduced from 260 to 96 attempts because compound assemblies now carry the normal cleanup language.

## Local terminal clearance hardening

A richer component layout exposed a pre-existing V36 edge case: a local terminal marker could run alongside a tall component border. The V36 marker backoff stopped after 1.6 routing modules; if that was insufficient, it returned the original invalid marker and relied on the final audit to reject the whole sample.

V37 allows marker retreat anywhere along the already-legal terminal polyline while preserving the normal 2.75-module minimum visible trace length. If no legal marker position exists, the optional local filler is pruned. Component clearance is never weakened.

## Preserved invariants

- `U = min(W,H) * main_scale / 1600`; no 0.75 multiplier.
- Default 1200×1200 canvas has exactly two main chips.
- Main network remains transactional-parallel with local-space causal traceback/re-route.
- Main network freezes before component placement.
- Components serve 50–60% of post-main residual capacity and freeze.
- Local lines serve 80–90% of the remaining service budget around frozen main routes and components.
- Pathway bodies remain straight segments with only 0/±45° turns.
- Exact chip/component/pathway/marker clearances remain hard.
