# V46 — Logical ViewBox + Locality-Preserving Optimization

V46 supersedes the revoked V45 release candidate.

## Architecture

- Removed public SVG width/height controls and `main_scale`.
- Added `aspect_ratio` + `scale` as the only geometry controls.
- Lower scale expands the logical `viewBox`; entity geometry remains canonical in logical units.
- Unified aspect extension and zoom on one logical-territory population/work law.
- SVG root emits no fixed width/height attributes.

## Correctness/performance fixes

- Replaced the large-N prepared-collection calibration state explosion with bounded deterministic quota solving; small-N legacy behavior remains differentially covered.
- Retry only an offending duplicate/near-duplicate collection in its already-calibrated category instead of restarting the entire population.
- Replaced per-chip/global head structures with one labeled shared spatial index.
- Indexed source-family, parent/child, fragment, side and owned route-history state.
- Cached/versioned materialized lane geometry for nearby exact connection checks.
- Replaced terminal joins/marker all-pairs scans with exact spatial broad phases preserving historical pair ordering.
- Replaced complex whole-group component/pathway topology operations with exact primitive-local spatial checks.
- Vectorized residual/source nearest-geometry measurement without changing candidate coordinates or exact distances.
- Removed repeated global gap-site sorting and stale-site retries; live site availability follows accepted component geometry.
- Fixed accidental every-round retargeting of ordinary unbundled local traces; only real bundle release retargets.
- Bounded full-board local waves while scaling source/branch/trace opportunity with logical territory.
- Replaced local temporary-bundle all-pairs pairing with same-region radius spatial queries.
- Replaced per-reroute whole-board history scans with per-front segment ownership and transactional local restore.
- Replaced repeated residual-region/source quota scans with exact lazy heaps/spatial indexes.
- Spatialized exact final static-clearance/intersection audits.
- Added narrow visible-side progress repair: the 8-module visible floor is unchanged; a diagnosed singleton can only pass by physically extending through ordinary proposal/clearance rules.
