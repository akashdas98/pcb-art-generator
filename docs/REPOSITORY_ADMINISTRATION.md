# Repository administration

For Git status/diff/history, staging, commits, branches, tags, remotes and synchronization, perform only the requested administration. Do not add renderer edits, release/stress tests or benchmarks unless requested or needed for an accompanying content change.

Git metadata writes are expected. Isolated branches/worktrees are allowed; identify target checkout and ownership, preserve user changes, and integrate explicitly. If code changes are part of the request, qualify those against [workflow](WORKFLOW.md) before the administrative tail. Current task decisions live in [CONTEXT.md](../CONTEXT.md).
